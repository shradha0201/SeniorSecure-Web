# SeniorSecure - Legal Form Helper

SeniorSecure helps users answer step-by-step legal questions, save their responses, and download them for legal form filling. It includes voice assistance to help users with accessibility needs.

## Features
- Simple question flow
- Save answers and navigate easily
- Voice assistance for each question
- Downloadable summary

## Technologies Used
- HTML
- CSS
- JavaScript (vanilla)

## How to Run
1. Open `index.html` in any browser
2. Answer questions
3. Click 'Download Answers' on the last question
